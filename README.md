# 🍝 Pasta Lab 랜딩 페이지

가상의 생면 파스타 가게 **Pasta Lab**을 소개하는 간단한 정적 랜딩 페이지예요.
GitHub CLI(`gh`)로 레포를 만들고 업로드하는 연습용 프로젝트입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴 3종, 소개, 예약 문의, 푸터) |
| `style.css` | 스타일 (반응형 레이아웃, 카드 hover 효과) |

## 실행 방법

빌드 과정 없이 `index.html`을 브라우저로 열면 바로 확인할 수 있어요.

## 참고

- 메뉴, 가격, 주소, 전화번호는 모두 예시용 가상 정보입니다.
